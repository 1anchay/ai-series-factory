# ЧАСТОТА НОЛЬ — Studio 2D v1.0

**Новый сериал и новый движок.** Это не очередной патч старого проекта «ПОСЛЕ НУЛЯ», а отдельная рабочая фабрика анимированных историй, созданная после анализа загруженного пользователем видео «Блэкаут. Часть 2». В референсе простая 2D-графика с живыми изменениями объектов и читаемым текстом; теперь и у нас **реальные анимированные действия внутри кадра** вместо зума на лица.

## Как выглядит серия

- Вертикальное 9:16 — 720×1280 на выходе, 20 FPS по умолчанию.
- Первая серия «Сообщение из завтра», 15 коротких сцен и ~1 минута русского повествования.
- Предметы двигаются сами: рука тянется к радио, стрелка поворачивается, часы идут обратно, лампа мигает, силуэт проходит за стеклом, катушки магнитофона вращаются, а осциллограммы меняются по времени.
- Постоянные элементы интерфейса и цветовая палитра. Один и тот же стилизованный персонаж.
- Субтитры по фразам из **настоящего текста диктора**, не просто декоративный текст.
- Только оригинальная программная графика и синтезированные звуки; чужие видео и музыку проект не копирует.

## Запуск через GitHub Actions (основной режим)

1. Открой **Actions → Frequency Zero — voiced 2D series → Run workflow**.
2. Оставь `episode=001`, `tts=auto`, `resolution=720`, `fps=20`.
3. После успешной сборки скачай `frequency-zero-voiced-episode-001` из секции **Artifacts**.
4. Проверь голос, ритм монтажа и написание надписей перед публикацией.

**`tts=auto`**: сначала пробуем естественный русский голос Microsoft Edge (`ru-RU-SvetlanaNeural`), при отказе сервиса — бесплатный голос Piper `irina`. Это не гарантированные облачные сервисы: для работы нужен доступ к источникам голосов из GitHub Actions. Если оба недоступны, выпуск **не создаётся**, а сборка честно завершается ошибкой.

`edge-tts` использует неофициальный онлайн-интерфейс. Перед коммерческой публикацией проверь действующие условия используемой службы. Для полностью локального, не зависящего от Edge режима выбери `piper`.

## Как создавать следующие серии

1. Прочитай `docs/SERIES_BIBLE.md` и сохраняй основные правила мира.
2. Добавь `episodes/002.json` по структуре `001.json`, используя существующие типы сцен (`cold_open`, `station`, `power`, `dial`, `signal`, `hero`, `clock`, `hall`, `warning`, `flashes`, `shadow`, `recorder`, `tomorrow`, `final`).
3. Добавь `002` в список опций поля episode в `.github/workflows/motion-story.yml`.
4. Запусти Actions.

## Локальный запуск

```bash
sudo apt install ffmpeg fonts-dejavu-core
pip install -r requirements.txt
python studio2d/validate.py --episode episodes/001.json
python studio2d/render.py --episode episodes/001.json --output output/frequency_zero_001.mp4 --voice auto --width 720 --fps 20
```

**Диагностическая озвучка:** `--voice espeak --preview` предназначена **только для проверки видеодвижка**, не для публикации. Она звучит роботизированно. Если для локальной системы доступен `espeak`, можно быстро проверить видео без сети.

## Честные ограничения

Это качественный по структуре **2D motion-story**, а не видеогенерация в стиле профессиональной full-frame анимации. Шагающие силуэты, движение стрелок/катушек и эффектов — настоящая программная анимация. Реалистичной пластики тела/лица здесь нет, и для нашего визуального стиля она не нужна. Готовность голосовой сборки подтверждается только успешным запуском на GitHub и просмотром результата.
