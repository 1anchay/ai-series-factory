# 🎬 ПОСЛЕ НУЛЯ — бесплатная фабрика вертикальных сериалов

Рабочая версия 0.1: **сценарии пишет ChatGPT в диалоге**, а бесплатный GitHub Actions собирает из них видео с русской нейроозвучкой, оригинальным атмосферным саунд-дизайном, анимацией, титрами и монтажом. **Без API-ключей, карт и платных нейросервисов.**

> Важно: это **анимированный motion comic**, не полноценная генерация фотореалистичного видео. ChatGPT не доступен как бесплатный автономный API внутри GitHub Actions. Новый сценарий можно добавить в `episodes/002.json` вручную (или поручить ChatGPT через подключённый GitHub).

## Запуск (одна кнопка)

1. Открой вкладку **Actions** своего репозитория.
2. Если GitHub просит разрешить Actions — нажми **I understand my workflows, go ahead and enable them**.
3. Выбери **🎬 Собрать серию бесплатно → Run workflow**.
4. Оставь `episode=001`, `voice=true`, `resolution=720` и нажми **Run workflow**.
5. После завершения открой запуск. Внизу, в **Artifacts**, скачай `series-001` — там `episode_001.mp4`.

В нормальном режиме Piper скачивает русскую модель голоса (~63 МБ) и синтезирует реплики локально на бесплатном CPU GitHub. Не требует учётной записи в сервисах озвучки.

## Как выпускать следующие серии

- Скопируй `episodes/001.json` в `episodes/002.json`.
- Поменяй `episode`, `title`, `scenes[*].narration`, `subtitle`, `art`.
- Допустимые `art`: `city`, `street`, `phone`, `look_up`, `window`, `double`.
- Лучше попроси ChatGPT написать продолжение по сохранённой «библии» сериала ниже.
- Нажми Run workflow и введи `002`.

### Как сделать картинку на порядок лучше

Создай шесть собственных вертикальных картинок (например, через ChatGPT в чате) и загрузи в репозиторий как:

`assets/001/01_city.png`, `assets/001/02_vera.png`, `assets/001/03_phone.png`, `assets/001/04_up.png`, `assets/001/05_window.png`, `assets/001/06_smile.png`.

Если картинка сцены есть, рендерер **сам заменит** процедурный рисунок на неё, добавив движение камеры, дождь, затемнение, цветокоррекцию и титры. Сюжеты, промпты и картинки для следующих серий можно делать в ChatGPT без автоматических внешних API. Изображения лучше делать **вертикальными 9:16, 720×1280 или выше**. Консистентность персонажей требует сохранения референсов.

## Библия сериала

**Название:** ПОСЛЕ НУЛЯ. **Формат:** мистический триллер, вертикальный 9:16, 25–45 секунд, крючок в первых 2 секундах, неожиданный финал.

**Вера:** 27 лет, короткие тёмные волосы, чёрная куртка, красный шарф, обычная горожанка. Во всех сценах должна выглядеть одинаково.

**Город:** вымышленный мегаполис под дождём, холодный сине-чёрный тон, редкие красные огни. В 03:17 электричество исчезло. Единственный свет — на 42 этаже башни.

**Тайна:** двойник Веры за стеклом знает, что произойдёт дальше. Сезон должен раскрывать источник «нуля» постепенно, а не сразу.

## Что сделано и ограничения

- ✅ Сценарий серии №001 написан ChatGPT; следующие можно добавлять так же.
- ✅ Бесплатный Python/Pillow рендер рисунков, параллакс, панорама, дождь, заставка и субтитры.
- ✅ Бесплатный ffmpeg кодирует MP4 H.264/AAC.
- ✅ Русский нейроголос Piper (модель загружается во время запуска; в офлайн-тесте доступно `--no-tts`).
- ✅ Оригинальный синтезированный саунд-дизайн, без чужой музыки.
- ✅ Приоритет пользовательских иллюстраций для повышения качества.
- ❌ Не создаёт фотореалистичное text-to-video на GPU.
- ❌ Не отправляет ролики автоматически в YouTube; публикация — вручную.
- ❌ Не вызывает ChatGPT сам по расписанию.

**Лицензии:** Проверь условия модели `rhasspy/piper-voices` для выбранного голоса, прежде чем монетизировать; не копируй чужие сериалы и персонажей. GitHub Actions для публичных репозиториев на стандартных runner бесплатен согласно GitHub Billing (правила могут меняться).

## Запуск на компьютере (необязательно)

```bash
pip install -r requirements.txt
python scripts/render.py --episode episodes/001.json --output output/episode_001.mp4 --no-tts --resolution 540
```

Для голоса просто убери `--no-tts` (потребуется интернет для скачивания модели Piper).
