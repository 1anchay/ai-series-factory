# 🎬 AI SERIES FACTORY — Cinematic v0.4

Бесплатный (без платных API) конвейер коротких вертикальных видео на **GitHub Actions**. Тестовая серия: **«ПОСЛЕ НУЛЯ»**, эпизод 001. Сюжет пока фиксирован: мы улучшаем именно производство.

## Что нового в v0.4

- **Шесть готовых кинематографичных изображений сцен**, созданных с ИИ, вместо простых нарисованных фигур. Файлы: `assets/001/01_city.jpg` ... `06_smile.jpg`.
- **Постоянный визуальный образ Веры** (тёмная куртка, бордовый шарф, мокрые волосы). В разных второстепенных кадрах внешность пока может слегка отличаться — для идеальной идентичности позднее потребуется единый character sheet и контроль референсов.
- **Плавные движения камеры, дождь, свет, туман, субтитры**, экспорт H.264/AAC 9:16.
- **Новый стереофонический саунд-дизайн**: городская атмосфера, дождь, электрическое отключение, раскаты грома, шаги, сигнал телефона, нарастающее напряжение и финальный акцент.
- **Русская озвучка Piper**: новые паузы между предложениями, более бережная компрессия и приглушение фона во время речи. В Actions можно выбрать `irina`, `dmitri`, `denis` или `ruslan`.
- **Поддержка раздельных слоёв для дальнейших сцен**: bg / mg / char / fg, с разной скоростью параллакса.

Важно: это **cinematic motion comic**, а не полностью сгенерированное нейросетью видеодвижение. Нет липсинка и актёрской анимации тела. Для большего реализма понадобится улучшать сами исходные материалы и анимацию.

## Запуск на GitHub

1. Открой `Actions` → **Build free cinematic episode** → **Run workflow**.
2. Введи `episode=001`, `voice=true`, `narrator=irina`, `resolution=720`, `fps=20`.
3. После успешной сборки скачай `episode-001` из раздела Artifacts. Внутри `episode_001.mp4`.

Установка Piper и загрузка модели при первом запуске требуют интернет. Никаких API-ключей и платных аккаунтов не нужно. На некоторых раннерах установка или скачивание модели могут завершиться ошибкой — в таком случае нужно прочитать лог Actions.

## Как добавлять свои кадры

Рендерер ищет изображения в следующем порядке:

1. Папка `assets/001/01_city/` со слоями `bg.png`, `mg.png`, `char.png`, `fg.png` — если есть, использует параллакс;
2. отдельный `assets/001/01_city.png`, `.jpg`, `.jpeg` или `.webp`;
3. встроенный процедурный рисунок как резерв.

Для других сцен: `02_vera`, `03_phone`, `04_up`, `05_window`, `06_smile`. Структура повторяется для следующих эпизодов.

Лучший исходник — вертикальное изображение 9:16, от 720×1280, без надписей. Текущие изображения сцен 03–06 частично собраны из кино-раскадровки, поэтому качество и детализация неодинаковы; это честный стартовый визуальный пакет.

## Изменение текста и сюжета

`episodes/001.json` задаёт `narration`, `subtitle`, продолжительность и тип эффекта каждой сцены. Пока **не переписываем сюжет**, а работаем над производством. Для новой серии можно скопировать в `episodes/002.json` и добавить отдельные изображения в `assets/002/`.

## Запуск локально

```bash
pip install -r requirements.txt
python scripts/render.py --episode episodes/001.json --output output/episode_001.mp4 --resolution 540 --fps 18 --no-tts
```

Убери `--no-tts` для озвучки. Можно выбрать голос через переменную среды `SERIES_NARRATOR=irina` (или `dmitri`). Потребуются FFmpeg и интернет для загрузки голосовой модели.

## Бюджет и ограничения

- Платные API не используются. GitHub Actions на общедоступных репозиториях со стандартными раннерами доступны бесплатно в рамках условий GitHub.
- Модель Piper скачивается из открытого каталога `rhasspy/piper-voices`, условия каждой модели нужно проверить перед коммерческим использованием.
- ChatGPT не может автоматически работать как бесплатный API внутри GitHub Actions; новые истории и изображения подготавливаются отдельно.
- Автопубликация на YouTube не включена. Сначала человек должен проверить результат.
- Окончательная оценка качества русского голоса требует прослушивания эпизода с `voice=true`.

## Исправления v0.5 (важно)

- Исправлены старые изображения, которые были вырезаны из коллажей: ролик теперь заполняет **весь экран 9:16**, без размытого окошка.
- Исправлена ошибка прозрачности, из-за которой нижняя часть кадров становилась непрозрачно-чёрной.
- **Субтитры теперь берутся из narration**, то есть совпадают с текстом, который читает голос, а не из короткого поля subtitle.
- Стандартный запуск через Actions оставляет `voice=true` и `narrator=irina`. **Если голос не создан, сборка должна завершиться ошибкой**, а не выдавать ролик без речи.
- Для теста без голоса есть отдельный режим `voice=false`. Его не следует публиковать как готовую серию.

Первый запуск v0.5 с нейроозвучкой на GitHub необходимо проверить в Actions. Локально тестировалась только визуальная часть, поскольку Piper в локальном окружении отсутствует.
