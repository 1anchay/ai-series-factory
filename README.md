# ЧАСТОТА НОЛЬ — сезон 1 · 8 озвучиваемых анимационных серий

**Новый движок 2D-историй v1.1:** сценарии восьми связанных эпизодов, анимация предметов и героя, отдельные звуковые эффекты и атмосферная музыка, русский нейроголос с выбором интонации для персонажей. Бесплатные сервисы; оплата API не требуется.

## Что добавлено

- **8 оригинальных сценариев:** `episodes/001.json` … `episodes/008.json`; развязка сезона и мостик ко второму.
- Дополнительные анимированные объекты: открывающаяся дверь, дверные стуки, телефон, записная книжка, зеркальный двойник, карта станций, архивная кассета, выключатель.
- **Отдельный звуковой слой** для стука, помех радио, щелчков, тревоги, шагов, переключателей, часов, шороха бумаги и кассеты.
- **Разные голоса:** Лика — Edge `ru-RU-SvetlanaNeural`; Кир — Edge `ru-RU-DmitryNeural`. Речь из радио дополнительно фильтруется. Если Edge недоступен, используется бесплатный Piper (но тембр мужского персонажа может не отличаться).
- **Ударения:** для сложных слов можно добавить поле `tts_text` в JSON сцены. В нём пишется отдельный текст для синтеза речи — с ё вместо е, уточняющими паузами, словами с ударениями или более однозначными формулировками. Основное поле `voice` останется текстом субтитров. Edge может не всегда соблюдать диакритику, поэтому важна ручная проверка на слух.
- **Предметные эффекты:** их можно прослушать отдельно в выходном `*_effects.wav` без голосовой дорожки.

## Запуск серии

1. Открой GitHub → **Actions** → `Frequency Zero — voiced 2D series` → **Run workflow**.
2. Выбери одну из `001`, `002`, …, `008`.
3. Укажи `tts=auto`, `resolution=720`, `fps=20`.
4. В Artifacts скачай видео и отдельную дорожку звуковых эффектов.

Рекомендуется сначала собрать `episode=002`: в ней много узнаваемых предметных звуков (звонок, радиопомехи, дверь, шаги).

## Локальный запуск

```bash
sudo apt install ffmpeg fonts-dejavu-core
python -m pip install -r studio2d/requirements.txt
python studio2d/render.py --episode episodes/002.json --output output/episode_002.mp4 --voice auto --width 720 --fps 20
```

Опция `--voice espeak --preview` только для технической проверки офлайн; для публикации не подходит.

## Сценарий и редактура

Каждая сцена имеет `id`, `kind`, `duration`, `voice`, `speaker`, `sfx`. Дополнительно допустимо `tts_text`. Все варианты сцен программно анимируются в `studio2d/art.py`, звуки в `studio2d/audio.py`, речь в `studio2d/voice.py`. Художественное ТЗ и характеры — [docs/SERIES_BIBLE.md](docs/SERIES_BIBLE.md).

## Текущие ограничения

Это выразительная 2D motion-story, а не генерация реалистичных движущихся видео. Edge TTS — сетевой сервис без гарантий неизменности и произношения; голоса нужно слушать и корректировать вручную. Технические тесты проверяют наличие речи и звука, но не заменяют человеческую оценку их качества. Автопубликация на YouTube отключена.


## Графика v1.2 — мягкий свет и более глубокое окружение

Новый `studio2d/atmosphere.py` отвечает за многоуровневую световую атмосферу. При этом сюжет, голоса, дизайн персонажей и композиция камер не менялись. Добавлены:

- кэшируемые мягкие световые ореолы для радиоприёмника, телефонов, ламп и дверей;
- движущаяся пыль, текстура фона, лёгкие отражения на полу;
- аккуратные световые акценты в коридорах и комнатах;
- защита от чёрных кадров/полос: тест `python studio2d/check_graphics.py` проверяет все 24 вида сцен в 72 контрольных кадрах;
- тест автоматически запускается перед сборкой ролика в GitHub Actions.

Это *поэтапное* улучшение 2D-графики, а не попытка заменить её реалистичным фильмом. Текст и речь остаются из сценария; громкость и произношение — отдельное направление доработок.
