# Стандарт графики для следующих серий

Вера — 27 лет, тёмно-каштановые мокрые волосы собраны сзади, естественное лицо, чёрная кожаная куртка, бордовый шарф. Ночной город без электричества, мокрый асфальт, синие тучи, единственное тёплое окно. Тон: тревожный реалистичный кинотриллер, не пародия на существующие сериалы.

Один 9:16 кадр для сцены: `assets/NNN/scene_id.jpg`, минимум 720×1280. Для будущей многослойной анимации: `assets/NNN/scene_id/bg.png`, `mg.png`, `char.png`, `fg.png` (фон/средний план/персонаж/передний план). Слои должны иметь прозрачный фон, кроме `bg.png`, одинаковую перспективу, ориентацию и размеры.

Не добавляй надписи или титры непосредственно в иллюстрацию: проект накладывает свои субтитры сам. Не допускай смены одежды, черт лица и положения предметов между кадрами, если это не требуется сценарием.

Сцены 001: 01 — отключившийся город и башня; 02 — Вера на улице; 03 — телефон и предупреждение; 04 — взгляд наверх; 05 — человек за светящимся окном; 06 — отражение, похожее на Веру.
