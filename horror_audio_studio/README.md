# СВЕТ ИДЁТ СНИЗУ — оригинальный русскоязычный мистический аудиосериал

## Концепция

**«Седьмая лампа»** — пилот самостоятельного короткого триллера. После отключения света в подъезде лампы загораются снизу вверх. Камеры пусты. Герой пытается понять, кто поднимается по лестнице, но угрозу выдаёт собственный домофон. Финал — на схеме дома появляется седьмой этаж, которого никогда не существовало.

Ориентир по жанру и производству — короткие российские анимационные триллеры с экспрессивной 2D-графикой, схемами и крупными субтитрами. Музыка, звуки и история **оригинальные**, дорожки и мелодии из референса не копируются; голос — стандартный нейроголос, а не клон человека из видеопримера.

## Аудиорежиссура

- **Речь:** один ровный низкий русскоязычный мужской нейроголос Дмитрий, `-8%` скорости, `-8Hz` высоты, паузы за счёт разбиения текста по сценам. Сцена 9 обработана как домофон.
- **Музыка:** оригинальный тревожный четырёхнотный мотив (D–E♭–A♭–B), басовый педальный тон, детюнинг, приглушённые колокольчики и редкие саспенс-нарастания. Это новая композиция, не мелодия из присланного видео.
- **Звуки:** щелчки проводки, включение ламп, шаги на лестнице, домофон, шипение, дверь, три удара, капли, электрический гул и финальный низкий удар.
- **Сведение:** музыка автоматически приглушается во время монолога. Звуковые события размещены в конкретных сценах. В конце — короткое затухание.
- **Экспорт:** `master.mp3` — всё вместе; `narration.mp3`, `music.mp3`, `foley.mp3` — отдельные дорожки; `subtitles.srt`; `cue_sheet.json`.

## Локальная сборка

```bash
sudo apt-get install -y ffmpeg
python -m pip install -r requirements.txt
python produce.py --episode episode.json --mode full --output output
```

Для прослушивания оригинальной музыки и звуков без речи, не используя сетевой синтез:

```bash
python produce.py --episode episode.json --mode music-only --output output
```

## Производственное ограничение

Сервис бесплатной нейроозвучки Edge требует подключения к его серверам. Если сервис временно недоступен, производство останавливается с ошибкой — чтобы не выдавать системную роботизированную речь за качественный выпуск.
