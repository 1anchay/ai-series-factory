# НОЧНОЙ ПРОТОКОЛ — «Сигнал под водой»

Новый **независимый** motion-story, созданный по изученному вертикальному видео: глубокий тёмно-синий фон, векторные объекты, самостоятельные движения, графические схемы, сигнальные кольца, крупные синхронные субтитры и редкие цветовые акценты. **Сюжет и графика оригинальные.** Чужие кадры, музыку, логотипы и текст не копируем.

## Ролик

- ~80–95 секунд в зависимости от скорости голоса; 576×1024, 30 кадров в секунду, H.264 + AAC.
- 19 анимированных сцен; 2D маяк, героиня, контрольная панель, диаграмма интервалов, радар, подводный кабель, камера, карта, башня на дне моря, финальная загадка.
- Оригинальные шум ветра/моря, гул, сигналы радара, щелчки, удары, радиопомехи — создаются кодом, без сторонних аудиофайлов.
- Контроль цветовых акцентов и текстовых фраз встроен в рендерер.

## Запуск локально (диагностическая озвучка)

```bash
pip install -r requirements.txt
python studio/animate.py --episode episode.json --output output/episode.mp4 --tts espeak
```

Нужно установить `ffmpeg`, `espeak` и русскую локаль для `espeak`.

## Финальный вариант — нейроголос

```bash
python studio/animate.py --episode episode.json --output output/episode.mp4 --tts edge
```

Понадобится интернет для Edge TTS. Голос `ru-RU-SvetlanaNeural`, скорость `-6%`. При сбое **сборка завершится ошибкой**, а не выдаст файл с неожиданной роботизированной речью.

Есть workflow GitHub Actions `Night Protocol — build original motion short`; запусти по кнопке Actions → Run workflow, затем скачай готовый MP4 из Artifacts.

## Права и ограничения

Проект не воспроизводит сюжет или характерные персонажи исходного ролика. Он наследует общие приёмы анимации и монтажа. Автоматический рендер — это motion-story, **не фотореалистичная видеогенерация**. Субтитры переключаются пропорционально длине фраз: точного распознавания фонем нет.
