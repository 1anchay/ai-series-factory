# «Завтра нас меньше» — пилот v6: Cinematic Clarity

Версия v6 устраняет ключевые ошибки прошлой версии: одинаковые предметы поверх самих себя, автобус без корпуса, почти пустую доску имён и финальную запись, где был виден только один человек. **Рендер остаётся стилизованным 2D**, не фотореализмом.

## Быстрый запуск

В GitHub Actions открой **«Завтра нас меньше — режиссёрский пилот v6»**, нажми **Run workflow**, оставь серию `001`, озвучку `auto` (Edge TTS голос `ru-RU-SvetlanaNeural` с Piper fallback), `720` и `20 fps`. Забери MP4 в Artifacts.

Локально (диагностика без сетевой нейроозвучки):

```bash
python series/tomorrow_less/studio/check_v6.py
python series/tomorrow_less/studio/render.py --episode series/tomorrow_less/episodes/001.json --output output/znm_v6_diagnostic.mp4 --voice espeak --width 720 --fps 12
```

Для публикации **не** используй `espeak`. Для публикации `--voice edge` или `--voice auto`.

## Что изменилось в v6

- Добавлен `studio/v6_stage.py`: сцены строятся из согласованной геометрии и уникальных предметов, не из рисунка с наклеенным дублем.
- Автобус целиком из одного исходного изображения, открывание встроенных дверей внутри корпуса.
- Магазин: одна касса справа, товары слева, печатающийся чек.
- Ника показана с камерой **до** исчезновения, в тексте прямо сказано, что она видеоблогер.
- Одна школьная декорация повторяется во всех школьных сценах, без случайной смены окон и шкафчиков.
- Все семь имён читаются сразу; после ночи именно Ника отсутствует.
- Экран записи: семь цветных героев и **отдельный восьмой силуэт сзади**.
- 10 сцен, базовый монтаж 64,6 с + автоматическое удлинение при необходимости под речь, то есть планируем 65–75 секунд.
- Основной голос не изменён; сохраняем русский `ru-RU-SvetlanaNeural`.

Полное режиссёрское ТЗ: [`DIRECTOR_V6.md`](DIRECTOR_V6.md).

**Известный предел качества:** геометрия сцены пока рисуется в 360×640 и масштабируется до 720×1280. Следующий технический шаг — нативный рендер 720×1280 с более чёткими ассетами. Движение человека остаётся ограниченным 2D.

# ЗАВТРА НАС МЕНЬШЕ — v5 · Предметная 2D-сценография

Новый пилот **«Семь имён»**: 10 быстрых сцен вместо 18, полноценные 2D-иллюстрации предметов и сохранённый основной русский голос `ru-RU-SvetlanaNeural`.

## Что стало лучше

- Самостоятельные иллюстрации автобуса, камеры Ники, кассового аппарата, полок магазина, детского рисунка, школьной двери и фонаря.
- Все предметы отдельные прозрачные спрайты (их можно повторно использовать и анимировать), а **не вырезки из одной раскадровки**.
- В автобусе видно окна, двери, колёса, сиденья и табло; на кассе отчётливо видно `04:40`, в камере виден объектив и экран записи.
- Убраны три затянутые сцены знакомства; герой запоминается через действие и одежду, а не через список анкет.
- В пилоте 10 сюжетных сцен с понятной цепочкой: пустой город → пропавшая Соня → автобус → магазин → другие выжившие → школа → список имён → 04:40 → исчезновение Ники → восьмой силуэт.
- Основной нейроголос оставлен прежним; нет подмены на eSpeak в выпуске. Системный голос доступен **только** для локальной диагностики.

## Производство на GitHub

Открой **Actions → Завтра нас меньше — пилот v5 → Run workflow**. Выбери `episode=001`, `voice=auto`, `width=720`, `fps=20`. Загрузится MP4 и семь PNG-иллюстраций из Artifacts.
