# 🎬 ЗАВТРА НАС МЕНЬШЕ — новый сериал, отдельный конвейер

**Сюжет утверждён.** Оригинальный мистический 2D-триллер: семеро в копии пустого города, люди возвращаются в реальность по одному, но оставшиеся забывают вернувшихся. В GitHub существующие «Частота ноль» и «После нуля» не тронуты.

## Что готово

- Полная библия сезона: `BIBLE.md`, герои, порядок исчезновений, правила, 12 связанных серий и финал.
- Полный сценарий пилота: `episodes/001.json` — 17 анимированных сцен, озвучка каждой сцены.
- Собственный код 2D-сцены: `studio/art.py`, без статичных увеличиваемых фотографий и без платных API.
- Оригинальные звуки и стереомикс: `studio/sound.py`.
- Русская озвучка: Edge TTS, резервно Piper; eSpeak только для локальной диагностики.
- Независимый workflow `survivors.yml`, доступный во вкладке Actions.

## Как запустить

GitHub → Actions → **Завтра нас меньше — пилот** → Run workflow → `episode=001`, `voice=auto`, `width=720`, `fps=20`. Скачай Artifacts → `zavtra-nas-menshe-001`.

Проверять ролику нужно дважды: звук и картинку. Выпуск без речи НЕ допускается. Автоматическая публикация пока выключена.

## Почему не все 12 серий в workflow

Сначала выпускаем пилот и утверждаем вид героев. Сезонная библия уже содержит 12 связных серий, но остальные сценарии, рисунки и монтаж будут готовиться последовательно. Нельзя выдавать недоделанные главы за готовые ролики.

## Локальный диагностический запуск

```bash
sudo apt install ffmpeg espeak fonts-dejavu-core
pip install -r series/tomorrow_less/studio/requirements.txt
python series/tomorrow_less/studio/render.py \
  --episode series/tomorrow_less/episodes/001.json \
  --voice espeak --width 360 --fps 12 \
  --output pilot_diagnostic.mp4
```

⚠️ `espeak` — грубый тестовый голос. Для нормального выпуска запусти Actions с `auto`/`edge`, чтобы голос создался через Edge TTS.

## Творческие требования

- Кадр 9:16 без черных рамок, максимум 2 строки субтитров.
- Общий/средний план, понятные объекты: автобус, магазин, телефон, дверь, блокнот.
- Независимые действия объектов и персонажей; не зумировать лица.
- Мрачная но читаемая палитра: тёмно-синий, янтарный, красный.
- Текст диктора и титров совпадает по словам, а `tts_text` применяется только для произношения.
- Звуковые события привязаны к сценам; после монтажа обязательно слушать готовый MP4.

## Авторство

История, 2D-графика и программно созданные звуки оригинальны. Не использовать чужие кадры, аудио и персонажей «Блэкаута».


## Персонажи v2 — каждому своё лицо (2026-10-28)

- Семь постоянных рисованных героев вместо одинаковых человечков: прорисованные глаза/брови/нос/рот, индивидуальная причёска, одежда, возрастные черты, очки, борода и аксессуары.
- Эпизод 001 содержит три дополнительных кадра знакомства, чтобы зритель узнал всех по именам и голосовым репликам.
- На общем плане отображаются маленькие подписи, а в сценах знакомства — большие портреты и роли. Утром после исчезновения Ники остаются именно шесть конкретных героев, а не шесть случайных фигур.
- Библия внешности: `CHARACTER_GUIDE.md`, набор персонажей: `studio/characters.py`. Проверки непрерывности: `studio/check_cast.py`.
- GitHub прикладывает `character_sheet.png` вместе с роликом.
- В финальной реплике исправлена ошибка: Ника находится на третьей строке списка, а не на последней.

Это по-прежнему осознанно простая 2D-анимация, а не нейросетевое видео с реалистичными лицами.


## Локации v3 — полноценное окружение

Для всех сцен пилота создан отдельный модуль `studio/environment.py`. Он рисует узнаваемые места с перспективой и повторяемым окружением: пустая улица с домами, окнами, светофором, остановкой и лужами; спальня с мебелью и семейной фотографией; магазин с полками, товарами и кассовой зоной; школьное убежище с раздевалкой, шкафчиками, окном и припасами. Фон сохраняет единый стиль 2D и не увеличивается зумом.

Движения фона независимы от персонажей: дождь, движущаяся дымка, световые блики, пыль и небольшое мерцание ламп. Никакие платные сервисы и чужие изображения не используются.

Локально проверено 15 типов сцен, исполнение `check_cast.py`, полная диагностическая сборка `001` с системной русской речью и аудиодорожкой. **Для публикации** использовать GitHub Actions с `voice=auto` (Edge TTS, Piper резервно), а не локальный `espeak`.


## Режиссёрский патч v4 · «Семь имён»

- Сценарий стал самостоятельным трёхактным пилотом, с личной ставкой Аси, уликой 04:40 и видеозаписью пропавшей Ники.
- 18 осмысленных сцен, регулярная смена действия; Ника исчезает из памяти, а не из материальных записей.
- `studio/cinema.py`: свет, виньетка, тёплые и холодные источники, фактура, движущаяся пыль, обработка без letterbox или зума лиц.
- Различимые голоса: мужской Mark (Edge Dmitry) и женские Asya/Nika (Edge Svetlana с разным темпом).
- `sfx=printer`, `sfx=tape`, `sfx=glitch`, обновлённый атмосферный саундтрек.
- QA: `python studio/check_story.py`, `python studio/check_cast.py`, `python studio/check_environment.py`.
- Экспорт остаётся 720×1280, но иллюстрационный холст рендерится в 360×640 с дальнейшим масштабированием. **Это не фотореализм и не настоящая 3D-анимация** — для этого потребуется следующий технологический переход к моделям video-to-video или набору high-res кадров.

Не публикуйте диагностический рендер `--voice espeak`: системный голос недостаточно выразителен. Рабочий GitHub Actions использует Edge TTS; на публичный релиз необходимо прослушать и утвердить речь.
