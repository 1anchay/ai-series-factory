# НУЛЕВОЙ ПАССАЖИР — самостоятельный 2D мини-сериал

**Это новая история и новый производственный проект.** Прежние сериалы не используются.

## Первая серия
«Кнопка, которой нет». 15 смысловых кадров, оригинальный сюжет, Aidar (Silero v5.6), оригинальная музыка и предметные звуки. 9:16, 576×1024, 24 кадра/с.

Главный герой — Артём, техник лифта с оранжевыми полосами на куртке. Его двойник **без** оранжевых полос. Главная загадка — нулевой этаж, счётчик невидимых пассажиров и исчезнувшая сестра Лена.

## Запуск
В GitHub Actions выбери workflow **Zero Passenger — full episode** и нажми Run workflow, либо скачай исходники и используй команду ниже после установки зависимостей.

```bash
python -m pip install -r zero_passenger/requirements.txt
python zero_passenger/studio/render.py \
    --episode zero_passenger/episodes/001.json \
    --cue zero_passenger/production_audio/cue_sheet.json \
    --narration zero_passenger/production_audio/narration.mp3 \
    --output zero_passenger/output/episode_001.mp4 --fps 24
```

Речь создаётся отдельным шагом через `horror_audio_studio/produce.py` (публичная модель Silero Aidar). Если речь недоступна, программа может сделать диагностическую версию, но её нельзя считать готовым выпуском.

Сценарии продолжения и правила мироустройства: `docs/SERIES_BIBLE.md`.

## Стандарт качества
- Нет чужой фонограммы, нет нарезок из референса, нет коллажей.
- Персонажи действуют внутри сцены; не приближай статичные лица.
- Максимум две строки крупных субтитров.
- В первой серии 15 самостоятельных действий; в каждой есть узнаваемый объект.
- Сначала проверяем голос и кадры, только потом публикуем.
